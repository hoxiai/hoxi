Hoxi Desktop v0.4.3

本次更新
- 内置浏览器新增交互控制：指针点击、滚轮滚动与滑动手势（前进/后退/滑动方向），并抽出 BrowserPreview 组件
- 新增浏览器状态栏，集中显示连接与页面状态
- 新增空闲后自动关闭 Chrome，避免长期占用资源
- Chrome Link 扩展同步新增导航动作与测试
- 审批策略新增可选轻量模型审查：对复杂的只读命令先由轻量模型判定，超时或存疑仍回退人工确认（默认关闭）
- 简化审批模式预设与确认卡片操作
- 修复 `env -u` 前缀未解包、`bash $HOME/.agents/skills` 脚本调用在受限展开校验中被误拒、以及 AI 审查提示词与自动模式不一致的问题
- 修复切换会话时的闪烁，并按工作区保留各自的新建会话草稿

升级提示
- 从 v0.4.2 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- 轻量模型审查需在设置中显式开启；开启后仅用于不透明的只读命令，破坏性操作仍走人工审批与硬底线
