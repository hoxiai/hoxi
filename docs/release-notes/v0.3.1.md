Hoxi Desktop v0.3.1

本次更新
- 修复 Windows 构建失败：`stopMarkerPrefix` 与 `openCodeStopMarker` 原先定义在仅 unix 构建的文件中，导致 Windows 目标编译报未定义符号；两者已移至平台无关文件，Windows / Linux / macOS 三端均可正常构建
- 该修复不影响 macOS 与 Linux 的运行时行为，仅为让三端构建保持一致

升级提示
- v0.3.0 的 Windows 包未能构建成功，Windows 用户请直接使用本版本
- 从 v0.3.0 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
