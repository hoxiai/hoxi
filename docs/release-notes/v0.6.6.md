Hoxi Desktop v0.6.6

本次更新
- 应用内更新会显示下载与安装进度，不再只有静态状态
- 发送消息后，回复替换「思考中」行时时间线不再上下跳动
- Antigravity 恢复会话时，过期的 trajectory 错误和服务器重启通知不再把轮次判失败
- 审批：子 shell 与 `bash -c` 里的字面量数据先遮蔽再判定，减少误报；审查模型不可用时回退到快速模型
- 待回答问题在工作区之间同步，时间线里的提问卡片可以直接作答
- 提高进程打开文件数上限，并跳过家目录、系统目录等过大根路径的代码索引，降低多会话时的资源耗尽

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
