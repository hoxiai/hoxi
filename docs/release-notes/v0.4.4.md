Hoxi Desktop v0.4.4

本次更新
- 版本记录改为发布到统一版本中心 hoxi.dev（appKey=hoxi-desktop）：多语言更新日志与三平台安装包一次写入，客户端自动更新检查同源
- 构建号 CFBundleVersion 改为数值版本号（Display 版本仍是语义版本），使 Sparkle 的版本比较与新版 appcast 一致
- 内置浏览器新增页面缩放重置与文件上传请求/取消（含页面对话框确认），并收紧动作校验
- 修复浏览器指针状态：仅在真正切换作用域/标签页时重置，跨帧替换保留按下的指针，避免拖动中断
- 修复技能目录失效后列表不刷新的问题；`@terminal` / `@changes` 提及改为边界限定（非仅空白）
- 本地网关允许列表纳入默认工作区目录

升级提示
- 本版是首个写入 hoxi.dev 版本中心的版本，macOS 自动更新将切换到统一 feed
- 从 v0.4.3 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
