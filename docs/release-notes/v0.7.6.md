Hoxi Desktop v0.7.6

本次更新
- 原生 Agent 引擎、上下文缓存与 Token 效率优化：将上下文预算锚定至服务商真实用量并在压缩时复用热缓存，修复 UTF-8 压缩高估、超大片段拆分重复摘要与代理环境下 OpenAI/Codex Prompt Cache Key 丢失问题；加固流式断连重试、HTTP/2 Keepalive、超时 Bash 自动提升与跨模型历史兼容，优化 MCP/规则/项目记忆/子任务与辅助 LLM 调用的 Token 开销，并完善代码索引截断计数与诊断作用域上报
- 远程协同门户、`hoxi.ui/v1` 富视图与分享交互升级：新增通用公共门户与中继扩展挂钩、远程协同门户、浮动协作输入框、短码中继路由、通用宿主互操作总线与跨站 OAuth 2.1 一键授权；上线 `hoxi.ui/v1` 聊天富视图、自动媒体画廊、本地视频内联传输与会话本地分享长图导出（含 Hoxi 点阵品牌标识），新增对话附件右键菜单与剪贴板图片复制，并精简桌面登录流程（支持真实取消）与修复繁忙态工具栏溢出
- 安全边界加固与 DevPulse 统计校准：强化桌面端 Token 鉴权、Wails 伪造头拦截、IPv6 `/64` 速率限制聚合、中继代理告警、Seatbelt 沙箱与仓库 MCP 环境变量隔离，限制隧道流 24MiB 上限并拒绝无头 E2EE 请求；修复 DevPulse 每日代码增删行确定性统计偏差与任务撤回持久化问题

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
