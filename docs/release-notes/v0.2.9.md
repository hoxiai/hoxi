Hoxi Desktop v0.2.9

本次更新
- 架构重构：Go 后端按领域解耦（hoxipaths、ocapi、ocstate、llm、agentcli），前端 store 与 services 严格单向分层并移除循环依赖
- 模型能力改为按家族与层级推断，移除硬编码的模型版本列表
- 修复 Provider 嵌套空值配置合并、Agent 配置写入作用域与模型推断的健壮性问题
- 多智能体 Convoy 迁移到 runner 会话平面运行，任务隔离与合并更稳定
- Runner 稳定性与性能：会话转录缓存限额、Turn 锁串行化、上下文分组精简，缓存清理时保留转录持久性
- 修复任务中途实时纠偏（Steer）、队列回滚与仅图标队列徽标的显示问题
- 修复审批卡片与 Shell 预览在命令执行期间的闪烁
- 修复 Codex、Gemini、Qoder 会话扫描的 sqlite3 JSON 列别名问题
- 隐私：以遥测 opt-out 替换原有 AI 同意门控
- 发版链路统一以 GitHub 为唯一发布源，GitCode 作为手动镜像

升级提示
- 从 v0.2.8 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
