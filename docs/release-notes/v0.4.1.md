Hoxi Desktop v0.4.1

本次更新
- 新增系统存储检视与清理（`GET /api/hoxi/system/storage`、`POST /api/hoxi/system/storage/clean`，设置 → 系统与运行时）：展示数据库、引擎日志与工具输出、会话存储、代码索引等占用，支持一键清理与定期清理
- 优化运行时查询：精简请求日志与召回来源查询、精简开发脉动历史读取、会话存储按磁盘状态增量落盘
- 修复工作树未跟踪文件的 diff、快照与 git 输出未设上限，处理大仓库时可能内存爆掉的问题；补充性能回归测试
- 减少审批打扰：跨目录 `cd`、读取技能目录与常见 Shell 惯用法不再反复询问，Go 与 JS 策略及共享用例保持同步
- 修复后台会话刷新失败未捕获的拒绝导致前端进程在测试与异常场景下崩溃的问题
- 测试隔离：存储清理测试固定数据库路径，避免开发机导出的 `OPENCODE_DB` 把测试指向真实 `~/.hoxi/hoxi.db` 并误写

升级提示
- 从 v0.4.0 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- 清理前请先确认当前没有正在进行的任务，清理不会删除会话与消息等持久数据
