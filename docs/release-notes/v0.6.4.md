Hoxi Desktop v0.6.4

本次更新
- 更新器：空闲检查并行执行，更新弹窗与系统设置显示下载进度；重复启动会先交给已运行的实例再初始化守护进程
- 账号登录按服务器隔离凭据并在重启后保持登录；签到或账号接口失败时直接显示服务端返回的信息
- 服务商：402 与余额不足统一归类为额度问题，时间线显示「余额不足」卡片而不是服务商质量警告，并据此自动切换候选
- Windows：`hoxi://` 链接交给桌面端而不是 CLI；安装与更新前结束残留的 `opencode.exe`，避免占用安装目录；守护进程随 Hoxi 退出一并结束
- 时间线：有历史消息时发送新消息不再回弹；有长历史时会话只加载最新一页并保持阅读位置
- CLI 运行时工具名在时间线按界面语言显示；开发状态入口标题改为「今日 Token 用量」
- 文档与内置技能默认内容同步

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
