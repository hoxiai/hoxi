Hoxi Desktop v0.6.11

本次更新
- 时间线层级细化：只默认展开当前执行组，新任务开始时自动收起更早的已完成组（视口内平滑折叠，视口外立即收起并补偿滚动位置）
- 新流式步骤与思考块补上高度/透明度入场过渡，步骤间隔显示思考指示
- 二级 ToolCard 与 ThoughtBox 去噪：语义图标更克制、耗时与折叠箭头仅在悬停显示、Shell 命令摘要更简洁
- 模型在调用工具前的 1–2 行过渡说明并入活动组，不再单独渲染成一条消息
- 折叠的活动摘要隐藏待办步骤与冗余推理，运行中的工具保持可见
- 非文档场景的 Markdown 标题、间距与分隔线更紧凑；会话骨架居中；粒子 Logo 增加加载微光
- 修复长会话上滑时出现空白：跳过高度为 0 的折叠工具轮次，按可视轮次推进顶部挂载，提前预取历史分页并保证首屏上滑余量
- 修复非自动池会话在瞬态错误上静默重发提示词的问题；仅自动池会话才做同模型重试
- 修复过期的 `.git/index.lock` 遗留：超过 10 分钟无人持有的锁会自动回收，仍活跃的锁继续拒绝
- 修复提供商遥测快照的并发拷贝与原子落盘、损坏文件备份、删除时清除降级状态；中继 Key 文件变更后缓存失效
- 修复工作树移除时保留用户自定义 `.env`、原子维护 `.git/info/exclude`、Diff 纳入未跟踪二进制文件，并清理发现的仓库缓存
- 修复本地文件打开的符号链接替换竞态、runner 会话路由的响应体缓冲、超大归档二进制的拒绝
- 前端清理子 Agent 链接、Diff/历史修订与已删除会话的轮询定时器；删除自定义自动池时重置会话

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
