Hoxi Desktop v0.5.3

本次更新
- 检查器新增 Markdown 文档阅读器：标题大纲（TOC）、相对链接跳转、frontmatter 解析与阅读历史前进/后退
- Markdown 渲染增强：图片说明、任务列表与更完整的块级解析，流式输出保持稳定
- 记忆库与技能检查器视图、文件树交互优化
- Windows 持久化服务商登录状态，并加固 opencode 守护进程启动
- 发布流程校验 opencode.lock 内的二进制版本，并随包附带 Windows sqlite3 sidecar

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
