Hoxi Desktop v0.6.16

本次更新
- 开发脉冲按仓库统计：项目根计入所有本地分支的提交，隔离工作树只看自己的分支，切换工作树不再漏记或串记
- 提交的文件集合与缓存按仓库根区分，多个仓库的改动文件数量不再互相覆盖
- 今日未提交改动跨目标按仓库根去重，Hoxi 快照提交在所有目标上都被跳过
- 修复 Antigravity 已恢复的过期错误仍被判失败：后续步骤完成最终回复后不再显示历史轨迹错误，读取历史转写时也会同步清理
- 修复 Windows 终端记录里的 CP936 / Latin-1 乱码
- 修复任务完成后追加消息时的布局闪动
- 用量与脉冲视图补充提供商健康与遥测信息

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
