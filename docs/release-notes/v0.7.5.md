Hoxi Desktop v0.7.5

本次更新
- 用量历史极速加载与今日 Token 统计精准校准：新增轻量会话用量摘要缓存（`turns.usage.json`）、`/api/hoxi/dev-pulse/history` 响应/Git 历史多级缓存、请求取消与单飞合并、多仓库并发 Git 扫描以及定价本地盘缓存即时响应，大幅消除打开“用量历史”的卡顿与等待；同步修复 Codex（`cached_input_tokens`/`reasoning_output_tokens`）、Gemini CLI（`cached`/`thoughts` 与多模型混合口径）及 Antigravity（主会话与子 Agent `thinking_tokens`）的重复计数问题，在今日动态/用量历史/请求日志中排除导入外部会话的历史轮次，并升级前端多会话实时增量合并
- 统一模型能力、多模态业务槽位与图像编辑/翻译代理：统一聊天、图像生成/编辑、图像翻译、视频、语音及向量/重排模型的能力声明与业务槽位列表，支持异步图像编辑任务与图像翻译代理（含协议相对地址规范化与编辑请求头透传），修复编辑自定义或 OAuth 网关时误丢 `mediaModels` 或误选非聊天模型的问题，并将非聊天模型探活切换至 `/models` 与强化 SSRF 出口防护
- 展示层与交互体验升级：时间线与检视器新增交互式图表（支持单位感知）、实时预览画布、增强型代码/文件检视与工具输出呈现（含 `JsonTreeView` 全部展开、SVG 隔离与 Escape 快捷键加固）；桌面与移动端同步支持 `hoxi-context v1` 结构化引用芯片与可折叠引用卡片，并完善跨站 WebView 导航下的声明式桌面 iframe 桥接；移动端同步修复已完成会话误将后续消息排队的问题，发布 `Hoxi-Remote-0.7.5-android.apk`（`ai.hoxi.remote`）

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
