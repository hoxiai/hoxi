Hoxi Desktop v0.6.1

本次更新
- 修复 Intel（darwin-amd64）安装包在发布流水线中的验证：交叉架构产物不再尝试在 Rosetta 下执行签名后的 OpenCode sidecar（冷启动超时），改为校验 Mach-O 架构切片、代码签名与 Info.plist 版本，sidecar 仍以 opencode.lock 的 SHA-256 固定
- 其余内容与 v0.6.0 一致（Intel 安装包、会话自进程审批放行、长会话历史分页、会话切换保留阅读状态、未选模型发送提示、官方网关品牌统一）

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
