Hoxi Desktop v0.7.2

本次更新
- Windows 无边框顶栏与原生窗口控制：集成 Windows 无边框标题栏与原生风格最小化/最大化/关闭控件，支持顶栏双击最大化、活动画布底色自动同步，并提升浮层窗口控件层级避免被引导页遮挡
- Windows 运行时、路径与自更新加固：修复 Windows 自更新替换顺序与文件锁定重试机制（先替换 `Hoxi.exe` 并在替换完成后清理暂存目录）；自动解包标准 `npm`/`pnpm`/`yarn` Node `.cmd`/`.bat` 与无扩展名 shebang 包装器直调 `node.exe`，避免 `cmd.exe` 破坏 JSON/TOML 双引号参数；提取统一 `subproc.ResolveWindowsBash` 优先选用 Git Bash、忽略大小写清理 Git/SSH 凭据变量与混合大小写环境键，并修复资源管理器定位含空格路径与盘符根目录及误建多余原生会话问题
- 跨端路径规范化与审批策略一致性：前端新增统一路径前缀裁剪并修复 Windows 反斜杠与盘符大小写差异；对齐 Go 与 JS 审批策略对 Windows 盘符路径、临时目录、敏感系统目录及 Unicode 变宽大小写路径的处理，补充共享一致性回归用例并重编 `browser_plugin.mjs`
- 跨平台构建与发版管线完善：完善 Windows `amd64`/`arm64` 构建与交叉架构产物版本校验、修复全仓 Go 代码格式检查与前端分层边界，同步发布 `Hoxi-Remote-0.7.2-android.apk`（`ai.hoxi.remote`）

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
