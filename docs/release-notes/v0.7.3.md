Hoxi Desktop v0.7.3

本次更新
- 智能审批降噪、原因横幅与内联脚本授权：Go 与 JS 双端审批引擎新增安全 Shell 惯用法支持（`set` 容错选项、带引号 `mktemp` + `trap` 清理、`gofmt -l`/`realpath`/校验和等只读值类替换、非算术 `[[ ... ]]`、只读管道 `xargs` 与字面量路径花括号列表），重编 `browser_plugin.mjs` 并扩充共享放行与绕过拦截用例；审批卡片新增脱敏触发原因横幅（`approval-reason.js`），不泄露密钥或原始路径；新增桌面端会话内存级、可撤销的内联脚本类授权，并严格维持子进程、动态执行、凭据外发与受保护路径硬底线
- 远程工作应用概览、受控新建会话与移动端文件互传：新增 `GET /api/hoxi/work/apps-overview`、带 Launchpad 快捷指令/待审批计数及脱敏活跃账号标签的 `GET /api/hoxi/work/app-sessions/{appId}`，以及支持严格字段白名单、并发幂等与绑定失败自动回滚的 `POST /api/hoxi/work/app-sessions/{appId}`；移动端支持应用活跃账号提示、本机文档附件上传、工作区二进制文件预览与系统分享导出，同步发布 `Hoxi-Remote-0.7.3-android.apk`（`ai.hoxi.remote`）
- 跨平台发版管线加固：完善跨仓库桌面发版 Tag 预检、扩展嵌套构建与开源镜像工作流隔离门禁

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
