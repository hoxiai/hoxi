Hoxi Desktop v0.5.6

本次更新
- 内置浏览器新增「整页 · 适应宽度」尺寸：按面板宽度渲染整个文档高度，预览可滚动查看完整页面；窗口模式下会自动切到隔离浏览器
- 浏览器地址栏在中文输入法组合中按回车不再误触发跳转，点击「Go」后自动失焦并提交
- 工作区支持多个工作区共享同一目录，主文件夹保持唯一；目录索引在就地改名或移动文件夹后立即刷新
- 会话结束后新增内联的沙箱合并与提交卡片，可直接合并隔离工作树并生成提交说明
- Agent 提交说明只针对本会话改动的文件，避免把无关变更写进提示词
- 模型自动池在上游给出重置时间时按该时间冷却并自动切换候选，时间线显示「已自动切换模型」提示
- Hoxi 账号积分余额自动刷新，无需重新打开设置页
- Windows 子进程不再弹出控制台窗口；回滚不再打断正在运行的任务；临时目录中的草稿文件不计入变更数量
- 修复诊断日志在同一时钟刻度内的排序，清理已下线的 shoply-ops 内置技能

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
