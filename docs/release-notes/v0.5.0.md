Hoxi Desktop v0.5.0

本次更新
- 原生电脑控制（macOS / Windows）：按会话与工作树授权单个运行中应用，读取前台窗口并进行输入；每次输入走本机「允许一次」审批，不支持远程批准或无人值守输入，可暂停、撤销或停止全部授权
- 内置浏览器新增持久化桌面 Chrome 窗口模式，并支持 Chrome Link 扩展快速连接接管已打开的标签页
- Windows 平台补齐：原生 Win32 系统托盘、应用内自更新、原生通知 / 剪贴板图片粘贴 / PDF 与 RTF 抽取、进程树清理与崩溃回收、审批钩子与 CLI 发现
- 审批新增轻量模型 AI 审查自动选择，并对齐 auto 模式的审查策略
- 编排支持对话式子任务规划与内联卡片，可在会话进行中途派生后台子任务
- 审批门控收紧：写入 `.git/config`、`.opencode/`、`.claude/`、`.agents/`、`.hoxi/skills/`、`.vscode/settings.json` 等高危路径统一询问，临时路径判定修正

修复
- 审批审计清单与磁盘持久化改为原子同步，避免列表与落盘不一致
- 多文件夹工作区与 OpenCode 沙箱在保存时去重，支持原地替换项目目录并清理旧状态
- 待审批项在侧边栏就地定位，不再强制切换模式
- Windows 更新校验 zip URL 回退并同步上报暂存错误，修复 explorer reveal 退出码与浏览器窗口焦点
- 版本发布不再回退到旧版发布接口地址

升级提示
- 从 v0.4.4 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- 电脑控制与无人值守相关开关仅在桌面端设置，且电脑控制首个模型入口为 OpenCode `hoxi_computer`
