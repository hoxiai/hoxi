Hoxi Desktop v0.6.18

本次更新
- 按需沙箱加固：写规则时封掉所有已在监听的本机 TCP/UDP 端口，经本机 SOCKS/HTTP 代理或其他 Agent、IDE 的本机服务都无法把命令带出机器
- 列不出本机端口时不生成沙箱规则、照常询问，不再假设没有监听
- Unix 套接字只允许工作目录内，其他 Agent 的桥接套接字与系统 DNS 解析器不可达
- 沙箱内不可读其他 Agent 的登录凭据（Codex / Claude / OpenCode / Gemini）与 IDE 凭据锁文件
- 跨重启任务账本：在途轮次、`prompt_async` 与审批回复的幂等收据落盘，主动更新或优雅退出先等当前单步工具完成，新进程零闪烁续跑（OpenCode 保 KV Cache，原生 CLI 按 ExternalID 续接），编排 DAG 自动续接且不重复合入
- 按需 Seatbelt 沙箱兜底：auto/完全信任下「本来要问、只因看不懂」的命令改为沙箱内直接执行
- 审批规则匹配改为字面量比较，5000+ 条「始终允许」不再每次编译正则
- 附件：新增原生 .xls 解析、表格单元格内联编辑与 PDF/表格预览，保留未编辑的 xlsx/csv 数据
- 新增 `hoxi doc` CLI 与文档读取策略，时间线预览可点击
- 修复回滚后新消息不可见、OpenCode 系统提示在插话与交接中字节不稳定、Antigravity 分叉会话续接、超长 JSONL 尾部撕裂等问题
- 隧道自动注册默认中继并强制中继令牌鉴权
- 提供商：官方目录按类别路由、Google/Anthropic 模型列表、推理强度变体对齐并在发送时收敛
- 技能按匹配度暴露并精简每轮提示上下文
- 敏感凭据文件访问改为桌面确认
- 性能：忙碌转圈改由 WebKit 合成器驱动，提示音播完释放音频设备

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
