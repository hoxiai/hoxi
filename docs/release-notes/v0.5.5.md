Hoxi Desktop v0.5.5

本次更新
- 审批 AI 审查适配推理模型：思考型模型不再因预算不足返回空结论，遇到上游不认 reasoning_effort 时自动去掉重试
- 审批卡片显示模型未放行的原因（模型请求确认、无结论、超时、回复无效、调用失败或模型未配置），并可跳转更换审查模型
- 内置浏览器 Chrome Link 会让所连接的标签页按检视器面板尺寸渲染，断开或点击「实际窗口尺寸」后恢复原尺寸
- 更新器在会话面板内显示 DMG 自更新进度
- 外部 CLI 会话接管按来源分页，修复繁忙工作区中某个来源列表为空的问题
- 加固 Hoxi 官方账号生命周期：凭据清理失败会明确提示，登出与重连串行校验，不再残留过期凭据
- Markdown 文档链接只解析一次并保留绝对路径

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
