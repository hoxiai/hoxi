Hoxi Desktop v0.2.10

本次更新
- 新增 GoPanel 反向隧道：Mac 主动外连 GoPanel，手机可在白名单路由内远程查看会话、下发指令并处理审批，待审批项经 APNs 推送提醒
- 隧道仅开放显式「方法 + 路由」白名单，模型列表以脱敏形式下发，不携带密钥与请求头
- 新增多智能体任务总览、指令草稿与完成通知
- 引擎卡片支持一键安装 / 重试 / 重启，安装失败自动回滚到可用版本，并固定 OpenCode 发布归档与 SHA-256 校验
- 新增按命令停止（stop-tool）能力，可中止单条仍在执行的工具调用
- Antigravity 全部工具调用统一接入 PreToolUse 审批门控
- Provider 表单支持密钥可见性切换；修复已移除的自动池候选被重新写入配置的问题
- 会话侧栏新增手动同步按钮，可刷新项目与已展开项目的会话列表
- 架构守卫扩展：拦截 scratch 文件、跨领域 Go 反向依赖、绕过 services 层直连宿主运行时等违规写法
- 时间线早期消息按动画帧分批挂载，长会话滚动更顺滑
- 修复远端停止请求因路由名不一致被拒绝的问题
- 修复 headless 会话中途退出、工具链命令规范化与跨工作区会话串扰问题
- 移动端已迁出至独立私有仓库，桌面端仓库保持精简

升级提示
- 从 v0.2.9 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- 远程控制需在 GoPanel 完成配对后才会建立隧道
