Hoxi Desktop v0.7.0

本次更新
- 进程内 Go 原生引擎全面就位：默认采用进程内 Go 原生 Agent 运行时与纯 Go SQLite 底座，无需外部 `opencode serve` 或捆绑边车进程；支持 `build`/`plan`/`ask`/`debug` 主模式、`general`/`explore`/`scout` 子智能体、异构子智能体模型路由、只读任务轻量模型自动选路、自定义 Markdown/JSON 角色与斜杠命令展开
- 原生执行与规划协同：新增 `plan_consent` 结构化规划确认卡片（批准后同回合无缝晋升 Build 模式），支持上下文窗口溢出反应式自动压缩续跑、文件编辑修订号租约校验、后台长命令执行与实时流式输出、`.gitignore` 双星号检索、多语言编辑后自动静态诊断（Go / TypeScript / Vue / Rust 离线 / PHP / Dart）及 Stdio MCP 冷启动预算与熔断
- 原生项目配置 `hoxi.json`：支持仓库根 `hoxi.json` 共享执行配置（与 `.hoxi/models.json` 本机凭据严格隔离，只读叠加不回写全局、不放宽本机审批），统一项目技能与代理目录至 `.hoxi/`，并将跨端审批策略收口至 `web/src/policy/` 与 `internal/runner/shellpolicy/`
- 零凭据数据连接、无头远程宿主与跨网 E2EE：新增 `hoxi_data` 零凭据连接档案（支持 HTTP、`sqlite`/`postgres`/`mysql` 词法级 SQL 只读门控与 `ssh` 只读白名单，凭据留存宿主并自动脱敏）；新增 `hoxi host` 无头开发宿主与桌面端远程挂载探活；升级 `hoxi-e2ee-v1` 流式加密、跨网 1-RTT X25519 密钥协商、单调 `seq` 增量补帧与三态持久化请求准入账本
- 桌面视觉与交互体验：新增多套 ACG 主题色板、自适应光学毛玻璃壁纸引擎与桌面看板娘伙伴组件（2x 无损立绘叠合矢量背景）；初始窗口尺寸自动适配屏幕工作区并记忆位置；重构精简错误卡片与账户菜单，降低空闲 CPU/内存与开发态热重载开销
- 安全加固、多运行时稳定性与开源生态：补齐 `~/.codex/`、`~/.local/share/opencode/` 及私钥证书敏感路径拦截，`hoxi -p` 空输入默认拒绝，原生按需 Seatbelt 沙箱与符号链接边界加固，源码构建默认关闭遥测并支持静默离线模式；修复统一反代思考签名保留、多步重试自愈、Antigravity 2.0 子智能体路由与删除会话 SQLite 级联清理；同步开放 Flutter 移动端远程控制器源码（`mobile/`）

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
