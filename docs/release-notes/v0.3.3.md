Hoxi Desktop v0.3.3

本次更新
- 新增“无人值守”审批模式：会话必须运行在隔离工作树并开启命令沙箱，沙箱内的 Shell 全部放行；读取密钥、任何 `git push` 与发布、`sudo`、携带凭据的外发立即拒绝，并写入仅桌面端可见的待处理清单。审批超时一律拒绝，不再放行，任务结束时推送一条仅含计数的摘要
- 审批门控更少误报：在 3,999 条真实命令回放中，完全信任模式的询问比例从 23% 降到 9.3%。只读循环、无害环境变量（`$HOME`、`$PATH` 等）、取值类 `$(…)`、带引号定界的 heredoc、字面量 `for` 循环与常量赋值、括号子 Shell 不再被当作看不清的命令；密钥读取、硬底线命令和无法判定的写法仍然询问
- 完全信任模式额外放行内联解释器脚本（`python3 -c`、`node -e`），以及 macOS `/var/folders/<id>/T/` 下具体条目的删除；会话可以读取自己的 `~/.hoxi/sessions/<本会话 ID>/` 记录
- 审批审计与诊断日志会脱敏更多密码写法（`PW=`、`mysql -p…`、`curl -u user:pass`、URL 内嵌凭据）
- 停止单条 OpenCode 命令后立即返回，不再等 120 秒超时；Hoxi 内部停止标记不再泄露给模型
- 新增 Chrome Link 扩展：可接管你已打开的 Chrome 标签页，沿用现有登录状态，无需开放远程调试端口
- 用量与费用页：默认显示全年热力图概览，新增按模型统计、平均耗时与自定义日期范围；导入的外部 CLI 会话按真实用量计入，修正 Codex 用量的重复累计
- 局域网令牌与中继令牌分离：中继入口只认独立的中继令牌
- Git 共同作者署名默认只加在 Hoxi 隔离会话工作树的提交上，可在设置中改为全部或关闭
- 修复正式版与开发版同时运行时 Grok CLI 失效的问题：每个进程都只连接自己的本机桥接
- 修复侧边栏任务偶尔同时出现在两个工作区下，以及启动阶段新建的会话没有出现在侧边栏
- 任务列表收进输入框右侧的进度环，设置导航合并为更少的分组，图片预览改为居中卡片

升级提示
- 从 v0.3.2 可直接在应用内检查更新
- 手机端如果经 Cloudflare 中继连接，升级后需要在桌面「设置 → 远程」重新扫码，局域网直连不受影响
- “无人值守”与“完全信任”模式风险较高，仅在明确需要时开启
