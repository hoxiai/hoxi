Hoxi Desktop v0.4.2

本次更新
- 安全加固：关闭“先写后执行”技能绕过路径，Go 与 JS Shell 门控保持一致，并回收异常退出遗留的孤儿进程
- 修复 macOS 状态栏菜单动作触发的 Wails ExecJS 过度释放崩溃
- 进一步减少审批打扰：远程 `ssh`/`scp`、临时 heredoc、安全 home 路径、`find` 分组；取值类 `wc`/`curl`、数字范围循环、`xargs basename`、目录 glob；安全的 `find -path` 列举赋值与只读 `sed -n` 范围
- 修复 Antigravity 编辑/写入载荷在步骤更新与恢复轮次中被截断的问题，保留完整内容
- 修复 DSML 推理失控循环导致的长轮次卡住，被截断的轮次可自动恢复，并单独展示最终思考
- 对齐 Go 与 JS 安全门控判定；存储清理解耦；MCP OAuth 凭据改为原子持久化，避免并发写入损坏
- 测试稳定性：审批去重可被观测（重复请求确认已并入后才会答复），Hook 决策读取加上截止时间，重启与重试断言等待终态真正落盘，修复偶发挂起整包测试的问题

升级提示
- 从 v0.4.1 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- 审批打扰进一步减少，但硬底线（密钥读取、提权、强制推送、发布、结束进程等）在任何模式下仍会询问
