Hoxi Desktop v0.6.12

本次更新
- 修复 v0.6.11 升级后启动白屏：Work 工作区侧边栏在首次渲染时读取了尚未初始化的变量，导致只要本地存在工作区数据窗口就停留在空白页
- 修复 Windows 上工作树合并测试夹具受 `core.autocrlf` 默认值影响而失败的问题

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 若 v0.6.11 已白屏无法打开应用内更新，请从官网或 GitHub Release 手动下载安装本版本
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
