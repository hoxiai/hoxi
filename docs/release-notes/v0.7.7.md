Hoxi Desktop v0.7.7

本次更新
- 外部 CLI 一键接入与运行时发现增强：新增 OpenCode 一键免费配置、WorkBuddy CLI 自动发现与 Qoder 登录态检测，并将媒体路由指令随当前轮次下发而非写入系统提示词，降低外部 Agent 运行时接入与切换门槛
- 远程协作门户、实时预览与路径边界隔离：为 QA 与外部协作会话强制实施只读与可写路径范围边界，新增源域锁定的无头实时预览（支持目录浏览、导航异常自动重置、弹窗阻断与跨端缩放恢复）；精简协作门户卡片与提示词分层，支持脱敏文件 Diff 行数展示、已校验 Markdown 图表/富卡片适配、桌面续聊回传测试门户及中继设备标识与静态资源亲和隔离
- 审批体验优化与安全边界加固：对已验证的只读 Heredoc 免除冗余审批弹窗，同时封堵嵌套规则文件创建、Heredoc 后缀绕过、门户卡片源码/密钥泄露与跨设备隔离缺口；修复非 Git 本地会话路径检查、编辑工具报错渲染与外部协作任务挂起/幽灵续跑问题，并同步升级上游优先开源架构与净仓门禁

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
