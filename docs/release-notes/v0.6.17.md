Hoxi Desktop v0.6.17

本次更新
- Antigravity 会话支持运行中纠偏（Steer）：追加指令会结束当前轮并带着最新历史继续，不再提示不支持
- 纠偏与 `always` 授权：保留审批门控真正认可的授权，无人值守模式下优先拒绝而不是先放行
- 官方账号模型按类别路由，模型列表携带类别、模态与默认标记，便于自动选模与语音模型区分
- 修复跟随消息发送时的时间线与滚动闪动，以及 macOS 上转写区偶发闪烁
- 思考面板去掉模型自带的「I'm thinking through…」开场白，标题更简洁
- Antigravity 推理内容回填，读取工具的行号区间格式化更准确
- 修复交接回退时丢失最新助手轮次与 Path 工具编辑的问题
- 修复提示词派发、AGY 思考、停滞看门狗、Windows UTF-8 回退与 Git NUL 路径等审查边界问题
- Claude Monitor 按命令走审批门控，修正完全信任模式下的误判
- 清理 staticcheck 与 race 报告的问题

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
