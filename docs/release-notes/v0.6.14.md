Hoxi Desktop v0.6.14

本次更新
- 蓝色主题刷新：浅色背景、描边与阴影对齐客户端默认蓝色调，整体更清爽统一
- 侧边栏项目改用描边文件夹图标，展开/收起状态更清晰；选中行使用统一的选中底色
- 用户消息改为强调色卡片，完成标记去掉发光，视觉更安静
- 修复发送消息后视口被拉回旧的活动组：跟随实时尾部时不再补偿旧分组收起
- 修复 Windows 终端中文乱码，新增 CP936 / GB18030 解码
- 修复关闭全部会话时未等待 OpenCode 轮次收尾、以及忘记会话时未取消进程扫描
- 会话清理、原子落盘与存储边界收紧
- 任务运行中恢复输入框上方的改动文件浮动胶囊
- 新增发送滚动锚定的浏览器回归测试

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
