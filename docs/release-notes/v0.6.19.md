Hoxi Desktop v0.6.19

本次更新
- 新增 Work 商品目录：标准 MCP 店铺商品工作流、店铺商品管理界面、详情就绪标记与批量详情补全
- 1688 商品详情解析：抓取真实标题、包装信息与 SKU，渲染详情表格，保留阶梯价 MOQ，并校验卖家归属
- 多店铺防关联隔离与确定性电商测算引擎；新增闲鱼选品默认技能
- 支持隔离的浏览器卖家登录、快照合并与折叠式 API Key 界面
- Chrome 空闲自动关闭可配置（默认 30 分钟），空闲开销更低；修复误开 about:blank 窗口与地址栏污染
- 模型：对齐 2026 前沿模型参数、模态与上下文窗口；保留运行时推理档位；免费模型需明确证据才判定
- 多模态池路由、自动 ASR 回退、持久化向量与多协议中转；Gemini 与 `/v1/responses` 对齐、语音听写与混合语义代码检索
- 支持独立 antigravity-cli 可执行文件与动态 Gemini 4 模型；本地 CLI 订阅额度与每周用量可见
- 审批放宽：只读命令、有界数值循环、引号目录、组合 heredoc 临时链、测试过滤与取值查询等减少误报；OpenCode「始终允许」留在 Hoxi 内并支持按文件会话授权；沙箱会话收紧到按需 profile
- 修复 OpenCode 会话中毒后轮换、失败轮次错误保留、长任务文件改动摘要丢失
- 修复浏览器 SingletonLock 竞态、共享窗口作用域保护与 Chrome 优雅退出
- 性能：启动/内存/GPU 合成优化，历史索引与流式持久化批量化，项目切换与工作树轮询提速，转写搜索与高亮下沉，完成任务后释放入场动画层
- 修复 `hoxi image` 尾部参数与 Grok 图片生成透传；`hoxi doc` 与 CLI 帮助参数不再混入对话

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
