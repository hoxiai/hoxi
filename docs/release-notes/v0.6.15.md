Hoxi Desktop v0.6.15

本次更新
- 移除审批 AI 审查：危险命令直接进入人工确认，不再同步等待模型调用而拖慢审批
- 开发脉冲与用量历史口径统一：从会话工作树与项目根同时统计，沙箱会话与普通会话的代码速度一致
- 今日未提交的已跟踪改动与新增文件计入今日统计；按提交时间归属，跨目录去重并跳过 Hoxi 快照提交
- `build/` 忽略规则收窄为 `build/bin/`，受版本管理的安装器源码重新计入统计
- 大库查询优化：为 dev-pulse、历史与请求日志的会话-消息-片段关联强制索引连接顺序并加时间下界，切换工作树时复用全局每日用量缓存
- 会话列表热路径不再重复克隆会话记录、重复解析 Git 根
- Windows 新增忙碌时更新的原生确认框，与 macOS 共用同一准入逻辑；状态探测超时从 2 秒放宽到 10 秒
- 修复 OpenCode 子 Agent 与已删除会话在轮次结束或删除后仍残留忙碌/审批状态

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
