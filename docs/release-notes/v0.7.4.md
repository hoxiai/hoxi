Hoxi Desktop v0.7.4

本次更新
- Orchestrator + Executor 双模型模式：原生引擎新增规划/复核（Orchestrator）与代码实现/测试（Executor）双模型协作，支持粘性 Executor 线程、执行回执校验、故障隔离与回滚清理，并在模型选择器中提供专属配置面板与悬停摘要
- 工作区定时任务与 `hoxi_schedule` 工具：新增内置调度器（支持 Cron 与间隔触发、时区、预览、运行历史、连续失败自动暂停及并发编辑状态保护）、桌面管理弹窗、命令行 `hoxi schedule` 与受桌面审批门控的 `hoxi_schedule` 原生工具，远程隧道一律 403 隔离
- 多镜像断点续传更新器与系统代理支持：新增 `cdn.hoxi.dev` 与 GitHub Releases 多镜像自动切换、HTTP Range 断点续传与偏移量校验、低速/卡顿镜像自动切源、同名文件校验和隔离以及 macOS/Windows 系统代理自动识别；桌面端支持切换下载源
- 审批策略重构与跨模式硬底线对齐：完全信任（`trusted`）切换为低摩擦显式高危黑名单并复用动态执行解析器（拦截解码管道、命令/进程替换执行、关键字前缀 `eval`、变量拼接命令名、环境转储与浏览器凭据库），同步将显式高危底线共享至 `auto`/`smart` 模式；Go/JS 双端统一拦截 `.claude.json`、`.config/gh`、`.config/gcloud`、`Library/Keychains` 等凭据路径，新增单主机 SSH 会话授权、项目子目录 glob 循环支持及 `browser_plugin.mjs` 同步产物
- 电脑控制、浏览器、性能与稳定性加固：强化 macOS 辅助功能/遮挡检测与 `/goal` 长流程恢复，桌面独立 Chrome 窗口改用显式回环调试端口消除不支持标志横幅，优化跨项目近期会话渲染卡顿与 PR 并发风暴，新增原生 Agent 评测套件、JS/JSON 诊断、`outcome_unknown` 恢复界面、前端面板错误边界、图像局部重绘（`maskDataUrl`）与 SSRF/代理及 Hook 安全加固；同步发布 `Hoxi-Remote-0.7.4-android.apk`（`ai.hoxi.remote`）

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
