Hoxi Desktop v0.2.12

本次更新
- 默认审批模式改为自动放行（auto），升级后首次启动会迁移一次旧的审批模式设置，之后仍可在设置中手动切回智能或手动
- 审批卡片中的规则行改为直接结单：选择「始终允许」即按允许回复，选择「始终拒绝」即按拒绝回复，不再因破坏性请求隐藏外层按钮而无处可点
- 只持久化精确规则：通配规则（如 `git *`、`npm *`、裸 `*`）仅在本次会话内生效，避免 `git push --force` 之类的破坏性变体绕过审批；裸 `*` 拒绝规则永不落盘
- 跨目录访问按目标分级：同级工作区目录与 SDK 缓存等常规路径在自动/智能模式下直接放行，凭据文件（`.ssh`、`.aws`、`.npmrc`、`.env*` 等）与执行控制路径（`/etc`、LaunchAgents 等）在任何模式下仍需人工确认
- 新增侧栏「待处理」与「运行中」跨项目视图：分别汇总所有项目的待审批、未读完成与暂停会话，以及正在执行中的会话；两个视图只读取已缓存的会话列表与全局状态，切换时不会加载其它项目的会话内容
- 侧栏模式切换顺序调整为 多项目 / 待处理 / 运行中 / 单项目 / 最近任务，并白名单化持久化取值
- 修复工作树与子智能体会话的审批路由：审批回复会记住请求所属目录，并在子会话中正确匹配与拒绝
- 修复嵌套项目识别：主目录精确匹配优先于父级工作区登记的次级目录，避免嵌套仓库被归到父项目
- 修复跨项目会话与召回串目录：按会话自身目录过滤，不再把嵌套目录下的会话混入其它项目
- 加固审批审计脱敏与外部路径判定，Go 策略与前端共享策略保持一致

升级提示
- 从 v0.2.11 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- 升级后审批模式会变为自动放行一次；如需逐条确认，请在设置中改回手动或智能
