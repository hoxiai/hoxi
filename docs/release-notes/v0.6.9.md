Hoxi Desktop v0.6.9

本次更新
- 审批：`$"` / `$'` 只出现在双引号内部时不再按 ANSI-C 或 locale 引号解析，`rg "foo$"` 这类以 `$` 结尾的模式不再被误判
- 审批：放行安全的 `python3 -m <module>` 管道（如 `json.tool`），同时拦截 REPL 与代码执行/发布类模块（`code`、`pdb`、`timeit`、`twine upload` 等）
- 审批：`env`、`time`、`nohup`、`command`、`timeout` 与循环关键字之后的数据参数先遮蔽再判定，非字面量命令头一律询问，减少误报
- 审批：OpenCode 的 AI 审查回退到人工确认时，不再重复推送待审批事件
- 窗口：失效的 `assetdir`（缺少 `index.html`）会退回内置资源，不再显示空白页
- 窗口：回环地址跳过系统代理，开发服务器失联时立即回落，不再等待代理超时
- 窗口：外部开发服务器返回 502 时恢复原始 Host/URL 与响应头再交给网关，回退页面更可靠
- 开发：macOS WKWebView 的 Host 通过 Vite 主机校验，开发窗口不再 403 空白；Vite 允许读取仓库根目录下的跨目录资源

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
