Hoxi Desktop v0.2.11

本次更新
- 新增本机模型中转：在回环地址暴露 OpenAI 兼容的 `GET /v1/models` 与 `POST /v1/chat/completions`，供 Cline / Continue / Cherry Studio / Open WebUI / aider 等本机工具复用已配置服务商；请求体与 SSE 原样透传，只重写 `model` 字段并注入上游 Key，上游凭据不下发给客户端
- 中转认证使用独立 `hk-*` Key，`~/.hoxi/relay-keys.json` 仅保存 SHA-256 哈希，明文只在创建时返回一次；`hoxi-auto` 走自动路由池，该平面永不进入隧道白名单
- 新增 Agent Skills 市场安装：可浏览 hoxi.ai 线上技能目录并显式安装，校验 `sha256` 后原子写入 `~/.hoxi/skills/<slug>/`，不自动安装、不执行远程脚本
- 新增统一子智能体设置面板，集中管理各 Agent 角色与模型绑定，支持按子智能体维度配置
- 新增审批审计日志：审批决策持久化落盘并自动脱敏 `Authorization`、`Bearer`、`x-api-key` 等敏感凭据；会话授权可撤销
- 审批门控扩展：Claude Code 非 Bash 工具调用与 OpenCode 受保护路径、`external_directory` 一并纳入审批；策略只解析一次，含引号、反斜杠、`$(`、反引号等无法确定语义的输入一律转人工确认
- 跨项目会话状态与审批常驻：切换到其它项目时仍实时显示运行中状态并接收审批提醒
- 新增按命令停止（stop-tool）能力，可中止单条仍在执行的工具调用，并加固进程组终止范围
- 顶栏直接展示桌面端更新提示，更新主机配置独立拆分
- 时间线早期折叠消息按用户轮次计数，长会话滚动定位更准确
- 修复本机中转 Key 生命周期、市场安装校验与子智能体配置在多处边界下的问题

升级提示
- 从 v0.2.10 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- 本机模型中转默认不开启，需在设置中手动启用并创建 Key；请勿把中转端口暴露到公网
