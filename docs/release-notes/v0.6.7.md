Hoxi Desktop v0.6.7

本次更新
- 审批：`manage_task` / `manage_subagents` 的 status、list 只读查询不再弹确认，也不再被误判为死循环轮询
- 审批：`wait` / `wait_5_seconds` 等等待工具按只读处理，轮询检查任务状态时不再反复打断
- 死循环检测按实际 Action 判定，带引号的 Action 也能正确识别
- 死循环提醒卡片可直接选择“始终允许”，不再因属破坏性判定而隐藏该选项
- 消息定位与深链跳转只作用于发起它的会话与目录，切换会话或工作区后不再滚错位置
- 会话导出改为实时拉取完整快照：失败会明确提示且不保存残缺文件，不再静默导出旧的尾部记录
- 沙箱合并卡片收起时保留过渡动画，时间线不再因卡片突然消失而闪动；智能提交说明的过期响应不再覆盖已编辑内容
- 子 Agent 抽屉默认展开，手动收起后仅在子会话重新进入运行、待审批或命中搜索时自动打开
- 修复发消息失败时状态与转写分步更新导致的页脚闪动与错误提示丢失
- 侧边栏项目与子 Agent 行的宽度约束补齐，长标题不再撑破布局

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
