Hoxi Desktop v0.5.2

本次更新
- Windows 新增 NSIS 安装程序（-setup.exe）与一行安装脚本 install.ps1，并接入应用内自更新映射
- 内置浏览器检视器界面打磨：模式/登录/诊断提示改为悬停说明，窗口与 Chrome 连接模式分段控件重构，Chrome 配对码支持复制态与图标
- 修复全新启动时自动播种默认工作区的问题，并统一 Windows 路径归一化
- 发布构建强制要求 hoxi-work Work 面，并归一化 Windows 下的 Vite 路径

升级提示
- 已在 v0.5.0 / v0.5.1 的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
