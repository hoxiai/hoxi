Hoxi Desktop v0.6.8

本次更新
- 统一故障分类：流结束、网络中断等被识别为可重试的网络故障，自动切换会按瞬态错误重试，而不是直接判失败
- 自动切换与候选健康判定消费同一份故障结构，重试与冷却决策更一致
- 时间线流式渲染不再卡顿或停顿，隐藏上下文不再触发重复扫描，长会话更顺滑
- 步骤分组与思考面板首次展开时补齐过渡动画，不再瞬间撑开
- 消息查找与步骤摘要缓存经过校验，去重与重建更稳；话题跳转不再来回回退
- 审批静态门控收紧，新的浏览器会话使用独立配置目录，减少相互干扰
- 抑制失控的重复工具循环，并去掉重复的 Shell 命令头
- 子 Agent 与嵌套步骤的时间线顺序修复，展开状态更符合预期
- 内置浏览器与 Work 应用的存储作用域解析统一，随附 Skill 脚本同步更新
- 工程门禁：CI 增加 Wails 宿主隔离、网关/CLI 分层与 gofmt 检查，版本元数据与根 CHANGELOG 保持一致

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
