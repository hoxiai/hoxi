Hoxi Desktop v0.6.0

本次更新
- 新增 Intel（darwin-amd64）安装包，与 Apple Silicon 版本同时签名、公证并发布，Intel Mac 不再被排除
- 审批模式可放行会话自己启动的进程：`pkill`/`kill` 的目标全部属于本会话时无需再确认，其余命令仍按完整策略判定
- 长会话历史改为分页加载：打开会话只取最新一页，上滑或点「加载更早」再按页取，避免一次性解析整段转写
- 切换会话后保留工具卡片展开、长提示展开与已展开活动步骤的状态，阅读位置不再跳动
- 未选择模型时发送会保留草稿、提示「先选择模型」并打开选择器；发送错误不再瞬间消失
- 官方网关去除 AINode 品牌，统一为「Hoxi Gateway」，端点从站点接口解析，不再写死主机

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
