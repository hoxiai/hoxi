Hoxi Desktop v0.3.2

本次更新
- 新增“完全信任”审批模式：在自动放行基础上，额外放行可恢复的破坏性操作——会话隔离工作树内（`.hoxi/worktrees/`）的 `rm` / `rmdir` / `unlink` / `chmod`，以及其中的 `git reset --hard`、`git checkout --`、`git restore`、`git clean`，另含删除 `/tmp`、`$TMPDIR` 下的具名条目；该模式只能在桌面端开启，不经隧道或局域网修改
- 破坏性判定不再误伤数据参数：提交说明、搜索词、`echo` 文本等字面量先做掩码再匹配，`git commit -m "...restore..."`、`rg "Shutdown"`、`grep "kill -9"` 不再被当成破坏性操作；含命令替换、heredoc、子 Shell、管道进解释器的输入仍一律转人工确认
- 硬底线在任何模式下都保持询问：密钥与凭据读取、敏感与可控制执行的路径、`sudo`、强制推送、共享 git 状态、发布类命令、结束进程、管道执行与死循环检测
- 修复合规与安全边界：仅附件路由接受 multipart 并校验其目录与会话字段，共享检出回滚限定为结构化编辑路径并持久化回滚范围，Qoder / CodeBuddy 非只读模式一律拒绝启动，版本后缀解释器与 `awk` 内联程序按不可判定处理，handoff 配置写入改为事务式更新避免并发覆盖
- 加固远程目录边界、审批门控、按范围本地回滚与配置原子写入，收紧单文件 diff、命令沙箱、远程审批与配置锁边界
- 会话侧自动池选模新增会话粘性：同一会话复用同一候选以保住上游 prompt 缓存前缀，粘性命中不占轮询游标，失败轮次仍会轮换
- 修复 Wails 下 `window.confirm` 不生效导致设置项（取消配对、关闭 Cloudflare、重新生成配对令牌、撤销中转 Key、重置设置、卸载 Hook）变成空操作，改用应用内确认弹窗
- GoPanel 授权配对后，远程设置面板展示面向手机的 relay 二维码（仅含面板与节点标识，不含凭据），手机可扫码把本机添加为中继节点
- 时间线上下文胶囊展示最大的三个上下文贡献项，便于定位上下文突增
- 工具卡片与历史记录不再显示 Hoxi 私有停止标记，命令行与描述按原始内容展示
- 跨项目新建与切换会话时展开对应项目并复用缓存，会话沙箱变更后同步索引
- 变更文件胶囊改为临时提示，并恢复按轮次提交

升级提示
- 从 v0.3.1 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- “完全信任”模式风险较高，仅在明确需要时开启
