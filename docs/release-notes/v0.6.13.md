Hoxi Desktop v0.6.13

本次更新
- 轮次重试有界：引擎给出的重试等待超过 15 秒、次数超过 3 次，或判定为永久/额度错误时立即中止并落错误，不再长时间静默等待
- 长重置提示按额度用尽处理并停止自动重试；`Retry-After` 始终落在重试上限内，避免无限退避
- 中止的重试会把错误写回会话最后一条助手消息，时间线能直接看到原因与建议
- 电脑控制授权更严格：按会话与应用收紧，检视器里能看到当前授权状态
- 配对轮询生命周期加固，设置菜单可直接查看配对进度
- 新增内置默认技能：A股操盘（ashare-ops）、港股窝轮牛熊证（hk-warrant-ops）、美股期权（us-options-ops）

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
