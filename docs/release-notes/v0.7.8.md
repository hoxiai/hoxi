Hoxi Desktop v0.7.8

本次更新
- 原生 Agent Prompt Cache 命中率与上下文精简：消除原生 GPT Prompt Cache 误失效与多模态误触发，重建分叉的 Gemini 缓存并加固宿主代理与保留期匹配；精简原生编码上下文并在前端展示缓存归零掉档与部分缓存命中遥测，评测同步基于实测缓存用量与原始测试集评分
- 协同运营模式、审批隔离与跨视图深链：新增通用 OP 协同会话工具门控、状态保护与前端扩展挂钩（支持标签页授权与远程图像编辑协同）；隔离不同视图的待处理审批队列，支持跨视图深链跳转并在会话索引更新后自动重解析挂起的深链作用域
- 原生下载保存与分享长图体验升级：新增 macOS `WKWebView` 下载原生保存面板与原子临时落盘重命名，统一文件保存路径反馈与定位入口；优化分享卡片的结构化引用展示、多页 PNG 批量原生保存与部分保存提示，并在预览与搜索中剥离引用上下文 XML，同步加固会话路径范围门控

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
