Hoxi Desktop v0.6.10

本次更新
- 更新：跨架构下载地址自动对齐到当前主机架构，从镜像拿到别的架构的 DMG / ZIP 不会再下载到不匹配的包
- 更新：校验和优先从同目录 `checksums.txt` 中按文件名匹配，避免回退到不完整的单行校验值
- 更新：安装 API 返回后应用会继续轮询原生进度，后台安装不再卡在进度条不再更新；阶段离开安装即停止轮询
- 更新：用户主动安装失败会明确报错，不再静默结束；后台发现的更新在重复点击安装时立即复用待处理回复，不再卡在重复检查
- 更新：有权限审批待处理时阻止更新，不只在会话运行时拦截
- 技能与发布：在线技能目录域名校验兼容自定义 `baseURL` 与 `HOXI_SERVER_URL` 覆盖；Release 附上每个 DMG 的 `.sha256`

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
