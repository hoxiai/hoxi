Hoxi Desktop v0.4.0

本次更新
- 新增 MCP OAuth 2.1（PKCE）服务商授权流程，并内置推荐网关清单；同时支持签发 Hoxi MCP 受限作用域令牌，打通 Work Apps 目录
- 新增内置 `hoxi_tools` 插件工具与本地工具网桥：OpenCode 会话内可直接调用，经 `GET/POST /api/hoxi/tools/*` 同构回环路由，端口动态协商并纳入沙箱与审批门控；内置技能 `hoxi-tools` 重命名为 `tools`
- 代码索引能力增强：AST 级符号边界、精确上下文切片、被调用者与多跳影响面分析、符号跨分块传播、调用方按语言与调用点排序，并做调用方预筛提速；新增代码索引 Agent 工具与 `hoxi code-index` CLI 子命令供原生 CLI 运行时使用
- 新增 Gemini CLI 运行时：`gemini` 纳入统一执行引擎并接入审批平面，个人版 OAuth 与 Gemini 4 / 3.8 模型经 `agy` 回落路由；放行 Gemini CLI 的沙箱状态写入，保留用户 `opencode.jsonc` 配置
- 工作区与代码区按界面类型隔离会话，切换模式即时生效；新建页、Composer 与会话记录跨界面切换保持挂载，并记忆各界面的会话状态，代码界面在刷新后仍记住
- 时间线流式体验优化：按节奏均匀上屏、新文本柔和淡入、平滑过渡，修复行内 Markdown 与标题闪烁、列表后幽灵空条目，并消除行内 Markdown 回溯与长轮渲染瓶颈
- macOS 状态栏菜单新增待审批与运行中任务的跳转链接与快捷操作
- 无人值守与审批加固：补齐环境变量清洗与动态代码硬拒绝绕过，停止的权限请求即时结单，无人值守计数在确认后记录且硬拒绝只审计一次，OpenCode 审批回复路由到会话工作树并避免重复超时审计，只读循环放行不透明命令门控，修复 Shell 不透明误判与停止标记泄漏，被拒的 OpenCode 超时拒绝按有界退避重试
- 沙箱调整：允许受限原生 CLI 读取钥匙串、解析符号链接的 home 目录、解开嵌套的 `sandbox-exec` 包装，并修复工作树模式切换、作用域守卫与沙箱胶囊交互
- 账号与签到：默认签到区间调整为 5,000~100,000 点并带数字千分位，设置中展示随机签到区间；本机 Work Apps 安装、自定义应用与技能绑定持久化到受保护的 `~/.hoxi/work-apps.json`；同步 401 登录态
- 修复 CLI 令牌计量、子智能体用量与请求日志，导入的 CLI 会话按真实用量统计
- 代码审查提取变更 hunk 便于审计；直接短标题跳过 LLM 摘要；压缩代码索引输出与通过态日志，去重恢复的 CLI 系统提示与 `project_memory` 段，剥离 ANSI/CR 噪声
- 开发模式在本机 `http://127.0.0.1:5400` 可达时默认指向该服务端
- 内置默认技能移除内部 shoply-ops；测试与注释清理本机绝对路径

升级提示
- 从 v0.3.3 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- 首次使用 MCP 授权或 Gemini CLI 运行时时，请在设置中按提示完成登录
