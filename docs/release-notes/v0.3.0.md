Hoxi Desktop v0.3.0

本次更新
- 远程访问成型：新增局域网配对二维码（`GET /api/hoxi/pairing/qr`），手机扫码后经局域网直连；桌面监听 `:5417` 并用配对令牌鉴权，仅服务局域网来源地址，配置了 Cloudflare Tunnel 时二维码另带公开中继主机名，手机按「局域网优先、失败回落中继」选路
- 新增 GoPanel 一键授权：桌面端可直接完成反向隧道配对，不必手工复制令牌；文档同步明确授权契约
- 新增受监管的 Cloudflare Tunnel 连接器：`cloudflared` 断线退避重启，令牌存 `~/.hoxi/cloudflared.json`（0600），管理接口只回状态、从不回令牌，二进制不自动下载
- 新增本机反向代理入口 `127.0.0.1:5418`，供本地转发器把公网请求代理进来，复用同一份远程路由白名单与配对令牌鉴权
- 配对令牌支持重新生成，旧码立即失效
- 设置面板重构为 7 个领域，审批策略统一收敛，默认沙箱模式与审批模式解耦
- 新增诊断请求日志：按请求记录模型、耗时、首 token 时间与单次成本，支持分页、过滤、进行中计时与详情抽屉，并新增错误日志
- 新增每日用量与成本统计：按历史记录精确汇总，带本地化单位，可从开发脉动直接打开完整用量历史
- 自动模型池新增候选熔断：按 `provider/model` 记录失败分类与延迟 EWMA，所有策略都会跳过冷却中与过慢的候选，更快更稳的模型优先
- 审批判定收敛到 Go 侧单一决策点，保留拒绝与对象规则、覆盖多运行时工具名，并解耦 shell 与文件规则
- 项目记忆迁移到 `<project>/.hoxi/memory/`，旧 `.opencode/memory` 仅作只读回退，不再向用户项目写入 `.opencode/`
- 新增 Git 提交共同作者署名设置，可按桌面前端开关
- 新增全屏图片预览，聊天与检视器中的图片可直接放大查看
- 设置中直接提示系统通知权限状态；语言列表英文在前
- 更新器支持周期后台检查，无人值守时只提醒一次
- 自动池模型选择器支持搜索
- 修复目标判定按整轮评估并接受运行时无关的结论行
- 修复 Grok / Codex 凭据需重新导入才能同步
- 修复回滚横幅在未真正回滚代码时仍显示
- 修复按命令停止 OpenCode 单条工具调用不精确的问题
- 修复隐私政策与服务条款链接未走系统浏览器
- 测试基础设施大幅提速：新增 `internal/testutil/execstub` 假 CLI 与各包 `TestMain`，可调超时替代真实等待，并修复脚本临时产物清理

升级提示
- 从 v0.2.12 可直接在应用内检查更新
- 有任务运行时更新会弹出确认，可选择“仍然更新”
- 远程控制默认不对外开启：需在「设置 → 远程」开启并完成配对；配对即授权，请妥善保管二维码与令牌
- `5417` / `5418` 为明文加令牌鉴权，跨网端到端加密尚未实现，请勿把这两个端口直接暴露到公网
