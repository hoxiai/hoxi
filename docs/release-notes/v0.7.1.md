Hoxi Desktop v0.7.1

本次更新
- 原生 Agent 引擎与智能编排升级：新增内置 `web_search` 网页检索、上下文窗口主动压缩与子目录规则历史去重、循环守卫及优雅收尾；新增会话级 Fast Mode（原生与外部 CLI 统一支持）、PageRank RepoMap 代码索引、Steer 前台长命令晋升、动态会话级 MCP 注入与只读轮次状态回查；优化文件/搜索长行守卫、重复读取去重与子智能体缓存隔离
- 多模态媒体工作流与行内预览：新增 `hoxi_video` 视频生成、`hoxi_speech` 语音合成、原生/本地模型能力自检与默认媒体角色配置卡片；统一工作区媒体暂存与回环流式预览（支持输入框视频播放与弹窗预览、`m4v` 识别、20MB 内视频直传原生多模态模型、音频自动 ASR 转写、聊天行内媒体与 SVG 预览）；新增内联 Mermaid 图表与文档/HTML 按需浮层预览，并加固远端媒体 SSRF 防护与二进制魔数校验
- 跨端协议、一键配对与任务协作：实现 `hoxi-app/v1` 回环发现、PKCE 授权流、宿主 MCP 暴露与桌面审批弹窗；新增零知识 6 位一次性配对码（含倒计时与取消）及独立 `hoxi-pairing-relay` 服务端入口；上线范围受控的 QA 任务入口门户（支持 Markdown 渲染、悬浮输入框与脱敏进度）；任务总览新增列表项移除与撤销，侧边栏拆分独立「近期任务」页签，并新增带敏感目录保护的原生目录选择器 API
- 品牌视觉、CLI 安装与安全门禁：全端升级清晰无摩尔纹的点阵 H 品牌图标，无损升级内置主题壁纸与看板娘立绘，修复壁纸模式暗色终端背景与侧边栏对齐；新增跨平台 CLI 一键安装脚本、软链自动升级与包管理器托管更新检测，支持提供商一键清理与本地 CLI 重新导入；强制 Go 四层 DAG、Provider 传输层防 SSRF 与插件产物字节级门禁，同步优化系统代理继承、Codex 模型目录、OAuth 刷新轮换与 Antigravity hook 自愈；同步更新开源移动遥控器 `Hoxi-Remote-0.7.1-android.apk`（`ai.hoxi.remote`）

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
