Hoxi Desktop v0.6.2

本次更新
- 新增 Windows on ARM（arm64）安装包与便携 zip，与 x64 版本同时构建、校验并发布；x64 机器仍使用 x64 安装包
- 官方渠道在 provider id 改名后自动修复，避免官方模型无法调用
- 模型设置：断开服务商改为弹层二次确认并显示加载状态，补齐缺失的确认文案，服务商操作错误不再被误导性的加载状态掩盖
- 排行榜始终实时拉取网关目录，不再展示过期缓存
- 审批：为 AI 审查留出足够回答时间，测试日志不再写入 `~/.hoxi`
- 工作树：共享的 `.opencode` 软链接不再被纳入沙箱提交
- 终端组件销毁时释放 WebGL 上下文，避免长期使用后显存/上下文泄漏
- 原生电脑控制每次都需要原生弹窗确认且为一次性授权
- Work 应用经 mcp-token 桥转发 store hints
- 首次启动新增「使用界面选择」引导页

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
