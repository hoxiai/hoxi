Hoxi Desktop v0.6.5

本次更新
- 侧边栏把子 Agent 会话折叠归组到父会话下方，运行中、待审批或命中搜索时自动展开
- 轮次遇瞬时网络或超时错误时自动退避重试：未跑工具就清空残余片段重跑，已跑工具则以续跑提示词恢复会话
- 大幅减少误报审批：只读循环与常量代入判定更准确，误判为不透明或破坏性的命令不再弹确认
- 审批 AI 审查放行内联解释器脚本，并在审查模型不可用时按 `provider/model` 回退到可用的审查模型
- 每轮结束时清理上一轮遗留的待审批与待回答项，不再跨轮残留；子 Agent 的审批 ID 与状态正确保留
- 时间线：流式输出时行内代码片段不再反复重挂载；选择运行中会话时自动聚焦最新输出；切换界面与 ThoughtBox 首次挂载的跳动消除
- 新会话激活批量化并保留乐观轮次状态，发消息时的界面回弹进一步消除
- 加固自动切换与失败回滚的竞态处理，收敛 OpenCode SSE 与快照负载体积

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
