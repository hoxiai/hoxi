Hoxi Desktop v0.5.4

本次更新
- 新增 Hoxi 官方账号（AINode）直连：用桌面端已登录的 Hoxi 账号一键连接官方渠道，独立于第三方网关服务商，互不覆盖
- 设置新增账号总览页，集中查看账号状态、官方模型与积分价格，并可从模型选择器直接进入
- 新增官方模型专属 Tab，未选中有效模型时优先使用官方模型，切换后保持所选模型
- 退出登录或凭据失效时同步清理官方渠道配置与引擎凭据，不再残留过期 Key
- 修复检查器裸链接末尾中文标点未剥离的问题，并自动开启预览

升级提示
- 已在 v0.5.0 及以上版本的应用内可直接检查到本版本并完成更新
- 从 v0.4.4 及更早版本升级需手动安装一次，之后才具备应用内更新能力
- 有任务运行时更新会弹出确认，可选择“仍然更新”
