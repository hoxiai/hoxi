# Project Memory Bank

## Core Architecture
- Desktop Engine: Go Daemon (`cmd/hoxi/main.go`) managing native lifecycle, process security & reverse proxy.
- Agent Runtime: Stock OpenCode Server (`opencode serve`) connected via loopback.
- UI Layer: Kilo-inspired standalone workspace with multi-session manager, collapsible reasoning stream, and instant diff inspection.
- Extensions: Automated safety permission auto-approver and incremental session knowledge reflector.
